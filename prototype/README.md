# REDITUS ARCANUM — First Floor Prototype

Python 3.13 + Pico2D로 만든 시작 화면, 캐릭터 선택, 1층 맵, 전투 프로토타입입니다. 기존 `images/A.png`–`D.png` 캐릭터 이미지를 사용합니다.

## 실행

프로젝트 루트에서 실행:

```powershell
python prototype/main.py
```

타이틀 화면에서 `게임 시작`을 누른 뒤 무작위로 제시되는 두 캐릭터 중 한 명을 선택합니다. 이어서 1층 맵이 열립니다. `Esc`는 타이틀에서는 종료하고, 캐릭터 선택·맵에서는 타이틀로 돌아갑니다. 맵의 덱 미리보기 중에는 창만 닫습니다. Python 환경에 `pico2d`가 필요합니다.

## 조작
- 카드 선택과 휴식: 방향키로 포커스를 옮기고 Space로 결정하거나, 마우스로 카드·휴식 버튼을 클릭합니다.
- 카드를 고른 뒤: 방향키로 대상을 바꾸고 Space로 공격을 시작하거나, 적 위로 마우스를 옮겨 화살표가 커서에 가장 가까운 적을 가리키게 한 뒤 해당 적을 클릭합니다. 취소 버튼 또는 Esc로 카드 선택으로 돌아갑니다.
- 타이밍 입력과 적 공격 방어는 Space 또는 화면 클릭으로 판정합니다. 패배 화면은 Space 또는 클릭으로 재도전합니다.

적이 공격할 때도 같은 타이밍 입력을 사용합니다. 입력 성공은 피해를 절반으로 줄이며, B의 PERFECT 방어는 회피가 됩니다.

## 1층 맵

출발 지점에서 첫 전투를 마치면 전투 노드와 상점 노드 중 하나를 선택하고, 이후 1층 보스에 도전합니다. 상점 노드는 현재 구매 기능 없이 통과합니다. 정예 노드와 유물은 PRD 범위에 따라 제외했습니다. 보스를 이기면 1층 클리어 화면에서 멈추며 2층은 없습니다.

일반 전투에서 승리하면 맵으로 돌아가며 다음 노드가 열립니다. 각 전투는 독립된 전투 세션으로 시작합니다.
노드 화면에는 네 명 기준의 동행자 슬롯이 표시됩니다. 캐릭터 슬롯을 클릭하면 해당 인물의 스킬 덱을 확인할 수 있으며, 닫기 버튼·같은 캐릭터 재클릭·바깥 영역 클릭 또는 Esc로 미리보기를 닫습니다.

## 구현 범위

- 무작위 2인 제시 후 1인을 선택하는 시작 흐름
- 한 갈림길이 있는 1층 맵, 전투·상점 표시·층 보스 노드
- 선택한 캐릭터 1명과 적 2체의 속도 순 턴 큐 및 동률 주사위
- 캐릭터별 5장 덱, 전투 시작 3장 손패, 최대 손패 5장, 버림패 재순환
- MISS/GOOD/PERFECT 공격 배율, 적 공격 타이밍 방어, 휴식과 C의 추가 드로우
- 출혈, 쇠약, 둔화, 기절, 강박, 취약 상태이상
- 캐릭터 A–D의 기본 특성, 전투 승패 화면
- 캐릭터별 투명 PNG 타격 이펙트, 적 타격 및 PERFECT 전용 이미지 오버레이
- A–D별 세로형 3:4 투명 카드 프레임, 상단 이름·빈 일러스트 영역·하단 설명 배치
- 1층 전투 화면 전용 숲터 배경 이미지 (`images/backgrounds/floor1_battle_background.png`)

전투 보상, 캐릭터 영입, 실제 상점 구매, 정예 전투와 유물은 아직 구현하지 않았습니다. 적의 미래 행동 예고나 강력한 공격 준비 표시도 없습니다.

## 요구사항 우선순위

현재 대화에서 사용자가 마지막으로 명시한 범위와 제외 사항을 먼저 반영하고, 세부 규칙은 `PRD.md`를 기준으로 삼습니다. `PRD.md`와 `pre_prd.txt` 또는 오래된 기획 PPTX가 충돌하면 PRD를 우선합니다. 적의 행동 예고·강력한 공격 준비·방향 입력은 화면에 표시하지 않습니다.
