# REDITUS ARCANUM — Battle Stage Prototype

실행 가능한 Python 3.13 + Pico2D 전투 화면 프로토타입입니다. 기존 `images/A.png`–`D.png` 캐릭터 이미지를 사용합니다.

## 실행

프로젝트 루트에서 실행:

```powershell
python prototype/main.py
```

전투 창에서 `Esc`를 누르면 종료합니다. Python 환경에 `pico2d`가 필요합니다.

## 조작

1. 현재 행동 중인 캐릭터의 손패에서 카드를 클릭합니다.
2. 공격할 적을 클릭합니다.
3. 타이밍 게이지의 중앙에 흰 선이 닿을 때 `Space`, `Enter`, 또는 창 안을 클릭합니다.
4. `휴식` 버튼을 눌러 카드를 보충합니다.

적이 공격할 때도 같은 타이밍 입력을 사용합니다. 입력 성공은 피해를 절반으로 줄이며, B의 PERFECT 방어는 회피가 됩니다.

## 구현 범위

- 캐릭터 A–D와 적 2체, 속도 순 턴 큐 및 동률 주사위
- 캐릭터별 5장 덱, 전투 시작 3장 손패, 최대 손패 5장, 버림패 재순환
- MISS/GOOD/PERFECT 공격 배율, 적 공격 타이밍 방어, 휴식과 C의 추가 드로우
- 출혈, 쇠약, 둔화, 기절, 강박, 취약 상태이상
- 캐릭터 A–D의 기본 특성, 전투 승패 화면

맵 진행, 전투 보상, 캐릭터 영입, 상점과 유물은 이번 전투 화면 범위에 포함하지 않습니다. 적의 미래 행동 예고나 강력한 공격 준비 표시도 없습니다.

전투 규칙 확인을 위해 시작 화면 없이 A–D 네 캐릭터가 모두 출전하는 단일 전투로 바로 시작합니다. 캠페인 시작 인원 선택은 아직 연결하지 않았습니다.

## 요구사항 우선순위

현재 대화에서 사용자가 마지막으로 명시한 범위와 제외 사항을 먼저 반영하고, 세부 전투 규칙은 `PRD.md`를 기준으로 삼습니다. `PRD.md`와 `pre_prd.txt` 또는 오래된 기획 PPTX가 충돌하면 PRD를 우선합니다. 다만 현재 대화에서 제외한 적 행동 예고·강력한 공격 준비, 방향 입력은 화면에 표시하지 않습니다. PRD의 카드·턴·휴식·타이밍 규칙과 기존 PPTX의 상태이상·캐릭터 특성은 구현 가능한 범위에서 반영했습니다.
