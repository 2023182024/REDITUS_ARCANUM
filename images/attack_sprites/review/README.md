# 캐릭터 공격 애니메이션 스프라이트 검토본

이 폴더의 PNG는 아델린(A), 네이라(B), 루미엘(C), 카르미나(D)의 공격 애니메이션 시트입니다. 현재 게임 코드에는 연결하지 않았습니다.

- 캔버스: 1536 × 1024 px, RGBA
- 배치: 2 × 2 프레임, 좌상단부터 오른쪽으로 읽고 다음 줄로 진행
- 프레임 영역: 각 768 × 512 px
- 순서: 준비 → 공격 동작 → 타격/마법 효과 → 후속 동작 및 복귀
- 용도: 검토 및 피드백 수렴 후 게임 적용

각 프레임 가장자리에 일부 투명 여백이 있으며, 런타임 적용 시 캐릭터별 공격 모션 타이밍과 프레임 크롭을 조정해야 합니다.
